# Live demo: C++ → WebAssembly, in three tabs

**Run it:** https://kevinwkt.github.io/from-cpp-to-the-browser/demo/

One page, keyboard-driven (`1` `2` `3` switch tabs, `R` race, `S` surprise me, `Z` zoom out, `0` reset, `+`/`-` page zoom).

## Tab 1 · The pipeline

Four C++ specimens from `specimens/`, each shown at every stage: the source, LLVM IR at -O0, LLVM IR at -O2, the WebAssembly text, and the bytes of the final module coloured by section. All of it is real compiler output generated by `gen.py`; nothing is hand-written.

| Specimen | What it shows |
|---|---|
| `01-add.cpp` | The slide specimen. 9 IR instructions → 3 → 5 WASM instructions, 14 bytes of code. |
| `02-template.cpp` | `Complex<T>` with operator overloads. 108 → 21: inlining + SROA make the template vanish. |
| `03-constexpr.cpp` | A palette computed by the frontend; 770 bytes in the data section, no arithmetic left. |
| `04-virtual.cpp` | A virtual call: vtable entries are table indices, the call is `call_indirect` with a signature check. |

## Tab 2 · The optimizer, measured

`fractal.cpp` (a Mandelbrot renderer written with that same `Complex<T>` template) compiled five ways, plus the identical algorithm in plain JavaScript:

| Build | Flags |
|---|---|
| `fractal-O0.wasm` | `-O0` |
| `fractal-O1.wasm` | `-O1` |
| `fractal-O2.wasm` | `-O2` |
| `fractal-O3.wasm` | `-O3` |
| `fractal-O3-simd.wasm` | `-O3 -msimd128 -DUSE_SIMD` (two pixels per instruction, `f64x2` lanes) |

"Race all" renders the current view with each of them (best of 3 after a warm-up) and checks that all six produce byte-identical pixels. Click the set to zoom; the detail slider raises `maxIter`.

## Tab 3 · The boundary lab

Calls into the same module: `add` (i32), `add64` (i64 ↔ BigInt), a string written into linear memory as UTF-8 and uppercased in place by C++, an `Int32Array` summed through a pointer, `memory.grow()` detaching old views, and the module's export list.

## Build

```bash
./build.sh                    # five fractal builds + pipeline.json (all checked in; optional)
python3 -m http.server 8000   # .wasm must be served over http
```

Toolchain: `clang++` with the wasm32 target, `wasm-ld`, and `wasm2wat`/`wasm-objdump` from wabt.

- macOS: `brew install llvm lld wabt` and `export CLANG="$(brew --prefix llvm)/bin/clang"`. Apple's clang has no WebAssembly backend; `lld` provides `wasm-ld` and is a separate formula.
- Linux: `sudo apt-get install clang lld wabt`.

No Emscripten, no libc, no libc++: `-nostdlib -fno-exceptions -fno-rtti`. Exports use `__attribute__((export_name("…")))`.

## Files

- `fractal.cpp` — the renderer: `Complex<T>`, a `constexpr` palette, the scalar and SIMD inner loops, and the boundary-lab helpers.
- `specimens/*.cpp` — the four pipeline specimens.
- `gen.py` — compiles the specimens through every stage and writes `pipeline.json`.
- `index.html` — the page. `basic.html` + `fractal-basic.c` + `fractal-basic.wasm` — the original one-screen version, kept as a fallback.
